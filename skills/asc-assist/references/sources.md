# Official sources and freshness

Authoring baseline: 2026-11-17. These official source entry points are not a claim of exhaustive policy verification. At execution time, verify the current rules needed for the actual platform, SDK version, locale and account. Record the consulted URL and observation date in private project evidence. If authoritative requirements cannot be checked, report the uncertainty and avoid claiming compliance.

## Apple

- [App Store Connect Help](https://developer.apple.com/help/app-store-connect/): app/version metadata, localization, build selection, roles, conditional requirements and current workflow.
- [Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications): current device sets, dimensions and formats.
- [Upload app previews and screenshots](https://developer.apple.com/help/app-store-connect/manage-app-information/upload-app-previews-and-screenshots/): upload behavior and editability.
- [App privacy details](https://developer.apple.com/app-store/app-privacy-details/): app and third-party data practices.
- [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/): applicable metadata, payments, privacy and account requirements.
- [Submit an app](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/submit-an-app/): used to identify and avoid review actions. Apple distinguishes draft Add for Review from actual Submit for Review; this skill stops before both.
- [App Store Connect API](https://developer.apple.com/documentation/appstoreconnectapi): verify supported resources and operation semantics before API writes; no submission operations are in scope.

## Providers

- [RevenueCat store connections](https://www.revenuecat.com/docs/projects/connect-a-store): applicable store configuration.
- [RevenueCat In-App Purchase key configuration](https://www.revenuecat.com/docs/service-credentials/itunesconnect-app-specific-shared-secret/in-app-purchase-key-configuration): key purpose, setup and handling.
- [RevenueCat API keys](https://www.revenuecat.com/docs/projects/authentication): public SDK keys versus secret server keys.
- [Google Mobile Ads data disclosure](https://developers.google.com/admob/ios/privacy/data-disclosure): SDK disclosure evidence; also inspect actual mediation partners and settings.
- [Google UMP for iOS](https://developers.google.com/admob/ios/privacy): consent integration and privacy choices.
- [AdMob Help](https://support.google.com/admob/): current app linkage and app-ads.txt requirements.
- [Firebase Apple-platform data disclosure](https://firebase.google.com/docs/ios/app-store-data-collection): product-specific behavior; actual app usage still determines final disclosures.
